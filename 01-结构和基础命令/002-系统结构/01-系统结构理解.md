把 Linux 根目录下这些主要文件夹逐个拆开讲。

每个目录统一按 **名称含义 → 核心作用 → 常见内容 → 使用注意** 来讲，

---

## 1. `/etc` — 配置中心

**名称含义**  
Etcetera 的缩写，历史上表示“其他杂项”，现在理解为 **Editable Text Configuration**（可编辑文本配置）。

**核心作用**  
存放系统级、主机特定的配置文件。系统启动、服务运行、用户登录、网络设置等，几乎都靠这里。

**常见内容**
- `/etc/passwd`：用户账户信息
- `/etc/shadow`：密码哈希
- `/etc/group`：用户组
- `/etc/fstab`：开机挂载表
- `/etc/hosts`：本地域名解析
- `/etc/ssh/sshd_config`：SSH 服务配置
- `/etc/nginx/nginx.conf`：Nginx 配置
- `/etc/systemd/system/`：systemd 服务单元

**使用注意**
- 需要 root 权限修改
- 改前最好备份
- 乱改可能导致系统无法启动或服务异常
- 有些文件是自动生成的，手动改可能被覆盖

---

## 2. `/bin` — 基本用户命令

**名称含义**  
Binary 的缩写，二进制可执行文件。

**核心作用**  
存放系统启动和修复所需的最基本用户命令，普通用户和 root 都能用。

**常见内容**
- `ls`、`cp`、`mv`、`rm`、`cat`、`echo`
- `bash`、`sh`
- `pwd`、`mkdir`、`touch`

**使用注意**
- 现代 Linux 多数做了 usr merge，`/bin` 通常是 `/usr/bin` 的软链接
- 一般只读，不要手动往里面放东西
- 用 `which ls` 或 `type ls` 可以看实际路径

---

## 3. `/sbin` — 系统管理命令

**名称含义**  
System Binary 的缩写。

**核心作用**  
存放系统管理命令，主要给 root 使用，用于启动、修复、管理网络和磁盘。

**常见内容**
- `fdisk`、`mkfs`、`fsck`
- `reboot`、`shutdown`
- `iptables`、`ip`
- `ifconfig`、`route`

**使用注意**
- 普通用户通常无权执行
- 现代系统里常是 `/usr/sbin` 的软链接
- 和 `/bin` 的区别：`/bin` 面向所有用户，`/sbin` 面向管理员

---

## 4. `/lib`、`/lib64` — 共享库和内核模块

**名称含义**  
Library 的缩写。

**核心作用**  
存放程序运行所需的共享库（`.so` 文件）和内核模块。

**常见内容**
- `libc.so.6`：C 标准库
- `libm.so.6`：数学库
- `/lib/modules/`：内核模块
- 动态链接器 `ld-linux.so`

**使用注意**
- 一般只读
- 删了会导致程序无法运行，甚至系统起不来
- 现代系统常是 `/usr/lib` 的软链接
- 用 `ldd /bin/ls` 可以看某个程序依赖哪些库

---

## 5. `/usr` — 用户级程序与共享数据

**名称含义**  
Unix System Resources，不是 “user” 的缩写。

**核心作用**  
存放用户级程序、库、文档、共享数据。通常是只读的、跨机器通用的。

**常见子目录**
- `/usr/bin`：大多数用户命令
- `/usr/sbin`：系统管理命令
- `/usr/lib`：库文件
- `/usr/include`：C/C++ 头文件
- `/usr/share`：共享只读数据，如 man、doc、icons、locale
- `/usr/local`：管理员手动安装的软件
- `/usr/src`：内核源码

**使用注意**
- 包管理器安装的软件大多在这里
- 一般只读，不建议手动改
- `/usr/local` 是例外，管理员可以自己装软件
- 你之前 `whereis ls` 看到的 `/usr/share/man/man1/ls.1.gz` 就在这

---

## 6. `/var` — 经常变化的数据

**名称含义**  
Variable 的缩写。

**核心作用**  
存放经常变化的数据，比如日志、缓存、数据库、队列。

**常见子目录**
- `/var/log`：系统和服务日志
- `/var/cache`：缓存，如 apt 缓存
- `/var/lib`：程序状态数据，如 MySQL、Docker
- `/var/spool`：队列，如打印、邮件
- `/var/tmp`：临时文件，重启后通常保留
- `/var/run`：现代系统常链接到 `/run`
- `/var/www`：某些发行版的 Web 根目录

**使用注意**
- 需要定期清理日志，否则可能占满磁盘
- 数据库文件在 `/var/lib` 下，不能随便删
- 和 `/usr` 相对：`/usr` 只读，`/var` 可写且常变

---

## 7. `/home` — 普通用户家目录

**名称含义**  
Home，用户的家。

**核心作用**  
存放普通用户的个人文件、配置、桌面、下载等。

**常见内容**
- `/home/alice`
- `/home/bob`
- 用户自己的 `~/.bashrc`、`~/.vimrc`、`~/.ssh/`、`~/.config/`

**使用注意**
- 用户自己可写
- 重装系统时通常保留 `/home`
- 不同用户之间默认不能互相访问
- root 的家目录不是 `/home/root`，而是 `/root`

---

## 8. `/root` — root 用户家目录

**名称含义**  
root 用户的家。

**核心作用**  
存放 root 用户的个人文件和配置。

**常见内容**
- `/root/.bashrc`
- `/root/.ssh/`
- `/root/` 下的脚本、备份等

**使用注意**
- 不是 `/home/root`
- 权限很严，普通用户无法进入
- 不建议把日常文件放这里

---

## 9. `/tmp` — 临时文件

**名称含义**  
Temporary 的缩写。

**核心作用**  
存放临时文件，所有用户都可以写。

**常见内容**
- 程序运行时的临时文件
- socket 文件
- 解压临时目录

**使用注意**
- 权限特殊，常有 sticky bit，用户只能删自己的文件
- 很多系统重启后会清空
- 不适合长期保存
- 有些服务用 `/var/tmp`，重启后保留

---

## 10. `/opt` — 第三方可选软件

**名称含义**  
Optional 的缩写。

**核心作用**  
存放第三方软件、商业软件、独立安装的软件。

**常见内容**
- `/opt/google/chrome`
- `/opt/lampp`
- `/opt/software/`

**使用注意**
- 通常每个软件一个独立目录
- 不被包管理器管理
- 卸载时直接删对应目录即可
- 和 `/usr/local` 的区别：`/opt` 更偏向独立第三方软件

---

## 11. `/srv` — 服务数据

**名称含义**  
Service 的缩写。

**核心作用**  
存放系统提供的服务数据，比如 Web、FTP。

**常见内容**
- `/srv/www`
- `/srv/ftp`
- `/srv/git`

**使用注意**
- 实际使用中不一定很规范
- 很多发行版默认是空的
- 管理员可以按需使用

---

## 12. `/mnt` — 手动挂载点

**名称含义**  
Mount 的缩写。

**核心作用**  
管理员手动挂载磁盘、NFS、ISO 等的临时挂载点。

**常见内容**
- `/mnt/disk`
- `/mnt/nfs`
- `/mnt/iso`

**使用注意**
- 通常由管理员手动使用
- 不是自动挂载点
- 和 `/media` 区分：`/mnt` 手动，`/media` 自动

---

## 13. `/media` — 自动挂载点

**名称含义**  
Media，媒体/介质。

**核心作用**  
系统自动挂载可移动设备，比如 U 盘、光盘、移动硬盘。

**常见内容**
- `/media/user/USB`
- `/media/user/CDROM`

**使用注意**
- 桌面环境自动管理
- 插入 U 盘后通常挂到这里
- 和 `/mnt` 区分：`/media` 自动，`/mnt` 手动

---

## 14. `/boot` — 启动相关文件

**名称含义**  
Boot，启动。

**核心作用**  
存放启动 Linux 所需的内核、initrd、GRUB 配置。

**常见内容**
- `vmlinuz-*`：内核
- `initrd.img-*`：初始化内存盘
- `/boot/grub/`：GRUB 配置
- `/boot/efi/`：EFI 分区挂载点

**使用注意**
- 不要乱动，删了可能无法启动
- 通常单独分区，大小几百 MB
- 内核升级时会自动更新

---

## 15. `/dev` — 设备文件

**名称含义**  
Device 的缩写。

**核心作用**  
设备文件的虚拟文件系统，反映内核识别到的设备。

**常见内容**
- `/dev/sda`、`/dev/nvme0n1`：磁盘
- `/dev/tty`：终端
- `/dev/null`：黑洞，丢弃数据
- `/dev/zero`：产生零
- `/dev/random`、`/dev/urandom`：随机数

**使用注意**
- 不占实际磁盘
- 由 udev 动态管理
- 不要手动创建文件
- 用 `lsblk`、`fdisk -l` 查看磁盘

---

## 16. `/proc` — 进程和内核信息

**名称含义**  
Process 的缩写。

**核心作用**  
虚拟文件系统，反映进程和内核状态。

**常见内容**
- `/proc/cpuinfo`：CPU 信息
- `/proc/meminfo`：内存信息
- `/proc/<pid>/`：某个进程的信息
- `/proc/sys/`：内核参数

**使用注意**
- 不占实际磁盘
- 只读或可调，不要当普通文件存数据
- 用 `cat /proc/cpuinfo` 查看 CPU
- 用 `sysctl` 调整 `/proc/sys` 下参数

---

## 17. `/sys` — 内核设备信息

**名称含义**  
System 的缩写，sysfs。

**核心作用**  
虚拟文件系统，反映设备、驱动、内核对象。

**常见内容**
- `/sys/class/net/`：网卡
- `/sys/block/`：块设备
- `/sys/devices/`：设备树
- `/sys/power/`：电源管理

**使用注意**
- 不占实际磁盘
- 用于查看和调整内核参数
- 和 `/proc` 有重叠，但 `/sys` 更结构化

---

## 18. `/run` — 运行时数据

**名称含义**  
Runtime 的缩写。

**核心作用**  
存放自启动以来的运行时数据，重启后清空。

**常见内容**
- `/run/lock`：锁文件
- `/run/user/<uid>/`：用户运行时目录
- PID 文件、socket 文件

**使用注意**
- 不占实际磁盘，tmpfs
- 重启清空
- `/var/run` 通常是 `/run` 的软链接
- 服务启动时在这里写 PID

---

## 19. `/lost+found` — 文件系统修复找回的文件

**名称含义**  
Lost and Found，失物招领。

**核心作用**  
`fsck` 修复文件系统时，找回的孤立文件会放到这里。

**常见内容**
- 编号文件，如 `#12345`
- 通常为空

**使用注意**
- 每个文件系统根目录下可能有
- 平时不用管
- 不要删除，但可以忽略

---

## 20. 一张表总结

| 目录          | 一句话作用           | 是否可写       | 是否主机特定 |
| ------------- | -------------------- | -------------- | ------------ |
| `/etc`        | 配置中心             | 可编辑         | 是           |
| `/bin`        | 基本用户命令         | 只读           | 否           |
| `/sbin`       | 系统管理命令         | 只读           | 否           |
| `/lib`        | 共享库和内核模块     | 只读           | 否           |
| `/usr`        | 用户级程序与共享数据 | 只读           | 否           |
| `/var`        | 经常变化的数据       | 可写           | 是           |
| `/home`       | 普通用户家目录       | 用户可写       | 是           |
| `/root`       | root 家目录          | root 可写      | 是           |
| `/tmp`        | 临时文件             | 所有用户可写   | 是           |
| `/opt`        | 第三方软件           | 一般只读       | 是           |
| `/srv`        | 服务数据             | 可写           | 是           |
| `/mnt`        | 手动挂载点           | 可写           | 是           |
| `/media`      | 自动挂载点           | 可写           | 是           |
| `/boot`       | 启动文件             | 一般只读       | 是           |
| `/dev`        | 设备文件             | 虚拟           | 是           |
| `/proc`       | 进程和内核信息       | 虚拟           | 是           |
| `/sys`        | 设备驱动信息         | 虚拟           | 是           |
| `/run`        | 运行时数据           | 虚拟，重启清空 | 是           |
| `/lost+found` | fsck 找回文件        | 一般不动       | 是           |

---

## 21. 记忆口诀

- **`/etc` 管配置**
- **`/bin`、`/sbin` 放命令**
- **`/lib` 放库**
- **`/usr` 放程序和数据**
- **`/var` 存变化**
- **`/home` 归用户**
- **`/root` 是管理员家**
- **`/tmp` 是临时**
- **`/opt` 装第三方**
- **`/srv` 放服务数据**
- **`/mnt`、`/media` 是挂载点**
- **`/boot` 管启动**
- **`/dev`、`/proc`、`/sys`、`/run` 是虚拟文件系统**
- **`/lost+found` 是修复找回**
