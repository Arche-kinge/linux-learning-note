查看文件树

tree 



可以，`tree` 支持很多参数（选项），而且可以组合使用。基本格式：

```bash
tree [选项] [目录]
```

例如：

```bash
tree -L 2
tree -a
tree -d
tree -L 2 -a -I '.git|node_modules'
```

常用参数：

| 参数                     | 作用                       |
| ------------------------ | -------------------------- |
| `-a`                     | 显示所有文件，包括隐藏文件 |
| `-d`                     | 只显示目录                 |
| `-L n`                   | 只显示 n 层深度            |
| `-f`                     | 显示完整路径               |
| `-i`                     | 不显示树枝线               |
| `-p`                     | 显示权限                   |
| `-u`                     | 显示所属用户               |
| `-g`                     | 显示所属组                 |
| `-s`                     | 显示文件大小               |
| `-h`                     | 文件大小人类可读           |
| `--du`                   | 显示目录累计大小           |
| `-D`                     | 显示最后修改时间           |
| `--dirsfirst`            | 目录排前面                 |
| `-P '*.txt'`             | 只显示匹配的文件           |
| `-I 'node_modules|.git'` | 排除匹配的文件/目录        |
| `-o filename`            | 输出到文件                 |
| `-J`                     | 输出 JSON                  |
| `-X`                     | 输出 XML                   |
| `-H baseHREF`            | 输出 HTML                  |
| `-C`                     | 彩色输出                   |
| `-n`                     | 关闭彩色输出               |

示例：

```bash
# 只看两层目录
tree -L 2

# 只显示目录，深度 1
tree -d -L 1

# 显示隐藏文件，但排除 .git 和 node_modules
tree -a -I '.git|node_modules'

# 显示权限、用户、组、大小、修改时间
tree -pugshD

# 输出 JSON 到文件
tree -J -o tree.json
```

查看全部参数：

```bash
tree --help
man tree
```

注意：有些 Linux 发行版默认没装 `tree`，需要先安装，例如：

```bash
sudo apt install tree        # Debian/Ubuntu
sudo dnf install tree        # Fedora/RHEL
sudo yum install tree        # CentOS 旧版
```
