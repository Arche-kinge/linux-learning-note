一句话总结：  
- `which` / `type` / `command`：查“你输入的命令到底执行谁”。  
- `whereis`：查“某个程序的二进制、man 手册、源码大概在哪”。  
- `find` / `locate`：查“文件系统里的任意文件”。  
- `grep`：查“文件内容”，不是查文件名。  

## 对比表

| 命令         | 查什么              | 搜索范围            | 是否实时 | 典型用途                           |
| ------------ | ------------------- | ------------------- | -------- | ---------------------------------- |
| `which`      | PATH 中的可执行文件 | `$PATH`             | 实时     | 命令可执行文件路径                 |
| `type`       | shell 如何解释命令  | 别名/函数/内建/PATH | 实时     | 推荐，判断命令类型                 |
| `command -v` | 命令解析结果        | shell 环境          | 实时     | 脚本中判断命令是否存在             |
| `whereis`    | 二进制、man、源码   | 系统标准目录        | 实时     | 查程序相关文件                     |
| `find`       | 任意文件            | 指定目录树          | 实时     | 按名字、类型、大小、时间等复杂查找 |
| `locate`     | 任意文件路径        | 数据库              | 非实时   | 快速按文件名全系统查               |
| `whatis`     | man 手册简述        | whatis 数据库       | 非实时   | 命令是干什么的                     |
| `apropos`    | man 关键字          | man 数据库          | 非实时   | 忘记命令名时搜命令                 |

## 1. which：查 PATH 里的可执行文件

```bash
which ls
# /usr/bin/ls

which -a python python3
# 显示 PATH 中所有匹配项
```

特点：  
- 只看 `$PATH`。  
- 不擅长处理 shell 内建、别名、函数。  
- 例如 `which cd` 可能找不到或找到错误结果，因为 `cd` 是 shell 内建。

## 2. type / command -v：更推荐

`type` 是 shell 内建，能告诉你命令到底是别名、函数、内建还是外部程序。

```bash
type ls
type -a ls       # 显示所有可能来源
type -t ls       # 只输出类型：alias/function/builtin/file/keyword
type cd
# cd is a shell builtin

command -v git
command -V git
```

脚本里判断命令是否存在，推荐：

```bash
if command -v git >/dev/null 2>&1; then
  echo "git 存在"
fi
```

## 3. whereis：查程序的二进制、man、源码

```bash
whereis ls
# ls: /usr/bin/ls /usr/share/man/man1/ls.1.gz

whereis -b ls    # 只查二进制
whereis -m ls    # 只查 man
whereis -s bash  # 只查源码
```

特点：  
- 搜索的是系统标准目录，不是整个磁盘。  
- 不按你的 `$PATH` 搜，所以自定义路径里的命令可能找不到。  
- 适合查“这个程序安装在哪、有没有 man、有没有源码”。

## 4. find：实时遍历目录，功能最强

基本语法：

```bash
find [路径] [条件] [动作]
```

常用示例：

```bash
find . -name "*.conf"
find /etc -iname "*.conf"              # 忽略大小写
find / -type f -name "nginx.conf" 2>/dev/null
find . -type d -name ".git"
find /var/log -type f -mtime -7        # 7 天内修改过
find . -type f -size +100M             # 大于 100M
find . -maxdepth 2 -type f -name "*.py"
```

结合 `grep` 搜内容：

```bash
find . -type f -name "*.log" -exec grep -l "ERROR" {} \;
```

删除文件，慎用：

```bash
find . -type f -name "*.tmp" -delete
```

特点：  
- 实时遍历，所以慢，但结果准确。  
- 搜 `/` 时权限错误很多，常加 `2>/dev/null`。  
- 查文件名用 `-name`，查路径用 `-path`。

## 5. locate：查数据库，快但可能过期

```bash
sudo updatedb
locate nginx.conf
locate -i readme       # 忽略大小写
locate -n 20 "*.conf"  # 限制结果数
```

特点：  
- 不是实时搜索，依赖 `updatedb` 生成的数据库。  
- 新文件可能找不到。  
- 适合快速全系统按文件名查。

## 6. whatis / apropos：查命令说明

```bash
whatis ls
# ls (1) - list directory contents

apropos "copy files"
man -k copy
```

`apropos` 等价于 `man -k`，用于忘记命令名时搜索。

## 7. grep：查文件内容

```bash
grep -r "listen 80" /etc/nginx
```

注意：`find` 查文件本身，`grep` 查文件内容，不要混淆。

## 怎么选

- 想知道 `ls` 实际执行什么、是不是别名：`type -a ls`
- 脚本判断命令是否存在：`command -v git`
- 查命令可执行文件路径：`which -a git` 或 `command -v git`
- 查程序二进制、man、源码：`whereis git`
- 找任意文件，按复杂条件：`find`
- 快速全系统按文件名找：`locate`
- 查命令用途：`whatis`
- 忘记命令名：`apropos`
- 查文件内容：`grep -r`

最常见的坑：  
`which` 不认识 shell 内建、别名、函数；`whereis` 不搜整个磁盘；`find /` 很慢且容易权限报错；`locate` 结果可能不是最新的。
