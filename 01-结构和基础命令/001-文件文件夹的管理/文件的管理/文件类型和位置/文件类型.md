Linux 里“文件类型”通常指 
**VFS/内核层面的 7 种基本类型**。

Linux 说“一切皆文件”，目录、设备、管道、套接字都算文件。


## 1. 七种基本文件类型

用 `ls -l` 看第一列第一个字符：

| 首字符 | 类型          | `find -type` | 说明                             | 例子                             |
| ------ | ------------- | ------------ | -------------------------------- | -------------------------------- |
| `-`    | 普通文件      | `f`          | 文本、二进制、图片、可执行文件等 | `/etc/passwd`                    |
| `d`    | 目录          | `d`          | 目录也是文件                     | `/home`                          |
| `l`    | 符号链接      | `l`          | 软链接，指向另一个路径           | `/usr/bin/python3 -> python3.11` |
| `b`    | 块设备        | `b`          | 随机访问，带缓冲，如硬盘         | `/dev/sda`                       |
| `c`    | 字符设备      | `c`          | 字符流，无缓冲，如终端           | `/dev/tty`                       |
| `p`    | 命名管道 FIFO | `p`          | 进程间通信                       | `mkfifo` 创建                    |
| `s`    | 套接字 socket | `s`          | 进程间网络/本地通信              | `/run/...`                       |

示例：

```bash
ls -l /etc/passwd /dev/sda /dev/tty /usr/bin/python3
-rw-r--r-- 1 root root ... /etc/passwd
brw-rw---- 1 root disk ... /dev/sda
crw--w---- 1 root tty  ... /dev/tty
lrwxrwxrwx 1 root root ... /usr/bin/python3 -> python3.11
```

## 2. 怎么查看文件类型

```bash
ls -l 文件              # 看第一列首字符
stat 文件               # File type 一行
stat -c %F 文件         # 只输出类型，如 regular file
file 文件               # 判断内容类型，如 PNG image data
file --mime-type 文件   # 输出 MIME 类型
mimetype 文件           # 类似，可能需安装
```

用 `find` 按类型找：

```bash
find . -type f      # 普通文件
find . -type d      # 目录
find . -type l      # 符号链接
find . -type b      # 块设备
find . -type c      # 字符设备
find . -type p      # 命名管道
find . -type s      # 套接字
```

## 3. 普通文件的内容类型

内核只把它当“普通文件”，具体是文本、图片、可执行文件，要看内容：

```bash
file image.png        # PNG image data
file script.sh        # Bourne-Again shell script
file /bin/ls          # ELF 64-bit executable
file archive.tar.gz   # gzip compressed data
file --mime-type a.pdf
```

常见内容类型：

- 文本：`text/plain`、配置文件、日志、脚本
- 二进制：可执行文件、共享库、目标文件
- 图像：`image/png`、`image/jpeg`、`image/webp`
- 音频视频：`audio/mpeg`、`video/mp4`
- 文档：`application/pdf`、`application/zip`
- 压缩包：`application/gzip`、`application/x-tar`

图形界面里，打开文件主要靠 **MIME 类型** 和 desktop 关联，不是靠扩展名。

## 4. 容易混淆的点

### 扩展名不决定类型

Linux 不强制用扩展名。  
`image.jpg` 可能是文本，`myfile` 可能是 PNG。  
真正类型用 `file` 判断。

```bash
cp photo.png photo.txt
file photo.txt     # 仍然显示 PNG image data
```

### 可执行文件不是单独类型

可执行文件仍是普通文件，只是有 `x` 执行权限：

```bash
chmod +x script.sh
./script.sh
```

脚本开头 `#!/bin/bash` 叫 shebang，决定用哪个解释器。

### 硬链接不是文件类型

硬链接只是多个文件名指向同一个 inode，不是新类型。

```bash
ln file hardlink      # 硬链接
ln -s file symlink    # 符号链接
ls -li file hardlink  # inode 相同
```

### 文件系统类型不是文件类型

`ext4`、`xfs`、`btrfs`、`NTFS` 是文件系统类型，不是文件类型。

```bash
df -T          # 查看文件系统类型
lsblk -f       # 查看块设备和文件系统
```

## 5. 特殊文件与虚拟文件

- `/dev`：设备文件，块设备、字符设备。
- `/proc`、`/sys`：虚拟文件系统，很多文件大小为 0，但读出来有内容。
- `/run`：运行时文件，常见 socket。
- FIFO：`mkfifo mypipe` 创建。
- socket：通常由程序创建，比如数据库、Docker、systemd。

## 6. 速查

```bash
ls -l                    # 看类型首字符
stat -c %F file          # 看文件类型
file file                # 看内容类型
file --mime-type file    # 看 MIME

find . -type f           # 普通文件
find . -type d           # 目录
find . -type l           # 符号链接
find . -type b           # 块设备
find . -type c           # 字符设备
find . -type p           # 管道
find . -type s           # 套接字

ln -s target link        # 创建符号链接
ln file hardlink         # 创建硬链接
mkfifo pipe              # 创建命名管道
```

一句话：  
**Linux 基本文件类型有 7 种：普通文件、目录、符号链接、块设备、字符设备、FIFO、套接字；扩展名只是习惯，真正类型用 `ls -l`、`stat`、`file` 判断。**
