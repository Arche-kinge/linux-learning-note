Linux 里“文件”不只是普通文档，

还包括目录、设备、链接、管道等。



日常操作主要分两类：

**图形界面**（文件管理器如 Nautilus、Dolphin、Thunar）

**命令行**。服务器一般用命令行。



## 1. 先判断文件类型和位置

```zsh
pwd                 # 显示当前目录
ls -lah             # 列出文件：-l 详情，-a 隐藏文件，-h 易读大小
ls -l 文件名        # 第一列看类型：- 普通文件，d 目录，l 链接，b/c 设备等
file 文件名         # 判断文件真实类型
stat 文件名         # 查看大小、权限、时间等元数据
tree -L 2           # 树形显示目录，可能需安装
```

> 在 Linux 语境下，**`stat` 通常指一个命令**，意思是 **status（状态）** 的缩写，用来查看文件或文件系统的详细状态信息。
>
> 你可以把它理解成：**比 `ls -l` 更详细地看一个文件**。

进入和切换目录：

```
cd /path/to/dir     # 进入目录
cd ~                # 回家目录
cd -                # 回上一个目录
```
