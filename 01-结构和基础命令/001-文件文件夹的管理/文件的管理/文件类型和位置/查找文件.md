理解成 Linux 里“各种查找”：
找文件、找内容、找命令、找图像、找重复/大文件、找最近修改等。

核心命令就几个：
**`find`、`locate/plocate`、`grep/rg`、`fd`、`which/type`、`file`**。


## 1. 按文件名 / 路径查找

```bash
find . -name "*.txt"                 # 精确匹配，区分大小写
find . -iname "*.jpg"                # 不区分大小写
find /path -type f -name "*.log"     # 只找普通文件
find . -path "*/cache/*" -name "*.tmp"   # 路径匹配
find . -maxdepth 2 -name "*.conf"    # 只找两层深
```

快速数据库查找，比 `find` 快很多：

```bash
locate -i "*.png"        # 可能需先 sudo updatedb
plocate "*.pdf"
```

现代替代工具：

```bash
fd -e jpg                # 找 jpg 文件
fd -e png -e webp        # 找 png/webp
fd -H -I "config"        # 包含隐藏文件，不忽略 .gitignore
```

## 2. 按类型、大小、时间、权限、所有者查找

```bash
find . -type f            # 普通文件
find . -type d            # 目录
find . -type l            # 符号链接
find . -type f -empty     # 空文件
find . -type d -empty     # 空目录

find . -type f -size +100M        # 大于 100M
find . -type f -size -1k          # 小于 1KB

find . -type f -mtime -7          # 最近 7 天修改
find . -type f -mmin -30          # 最近 30 分钟修改
find . -type f -newermt "2026-10-01"   # 某日期之后修改

find . -type f -perm 644          # 权限正好 644
find . -type f -user alice        # 属于 alice
find . -type f -group dev         # 属于 dev 组
```

## 3. 按文件内容查找

```bash
grep -rIn "error" .                     # 递归、行号、忽略二进制
grep -rIn --exclude-dir=.git "TODO" .
grep -rl "keyword" .                    # 只列包含关键词的文件名
grep -ri "hello" .                      # 忽略大小写
grep -E "error|warn|fail" file.log      # 正则
```

更快更现代的：

```bash
rg "error"                              # ripgrep，默认递归、忽略 .gitignore
rg -n --hidden --glob '!.git/*' "TODO"
rg -l "keyword"                         # 只列文件
rg -i "error"
```

查二进制里的字符串：

```bash
strings binary_file | grep "version"
```

## 4. 查找图像 / 媒体文件

按扩展名：

```bash
find . -type f \( -iname "*.jpg" -o -iname "*.png" -o -iname "*.webp" -o -iname "*.gif" \)
```

按真实 MIME 类型，比扩展名可靠：

```bash
find . -type f -exec file --mime-type {} + | grep "image/"
```

列出所有图片路径：

```bash
find . -type f -exec file --mime-type {} + | awk -F: '/image\//{print $1}'
```

查看图像信息：

```bash
file image.jpg
identify image.jpg        # ImageMagick
exiftool image.jpg        # EXIF 信息
mediainfo video.mp4       # 媒体信息
```

找最近修改的图片：

```bash
find ~/Pictures -type f \( -iname "*.jpg" -o -iname "*.png" \) -mtime -7
```

## 5. 查找命令、手册、程序位置

```bash
type ls                 # 是别名、内置还是外部命令
command -v python3      # 可执行文件路径
which python3           # 类似 command -v
whereis ls              # 二进制、源码、man 位置
whatis ls               # 简短说明
man -k keyword          # 搜索手册，等同 apropos
```

## 6. 找大文件、重复文件、磁盘占用

```bash
du -ah . | sort -rh | head -20          # 当前目录最大文件/目录
find . -type f -size +1G -exec ls -lh {} +   # 大于 1G
ncdu .                                  # 交互式磁盘分析，需安装

fdupes -r .                             # 找重复文件
jdupes -r .
rdfind -dryrun true .
rmlint .
```

## 7. 查找后直接操作

```bash
find . -name "*.tmp" -delete                    # 删除，慎用
find . -name "*.jpg" -exec chafa {} \;          # 对每个文件执行
find . -name "*.txt" -exec grep -n "error" {} + # 批量搜索
find . -print0 | xargs -0 ls -l                 # 处理带空格文件名
```

## 8. 模糊查找和交互式查找

```bash
fzf                     # 模糊筛选
fd -e jpg | fzf         # 找图片并选择
rg --files | fzf        # 文件列表模糊选
```

图形界面里：

- GNOME 文件管理器：`Ctrl+F`
- KDE Dolphin：搜索栏 + Baloo
- Catfish、Recoll、AngrySearch：桌面全文搜索

## 9. 最常用速查

```bash
# 找文件
find . -iname "*.jpg"
fd -e jpg
locate -i "*.png"

# 找内容
grep -rIn "error" .
rg -n "TODO"

# 找最近修改
find . -type f -mtime -7

# 找大文件
find . -type f -size +100M -exec ls -lh {} +
du -ah . | sort -rh | head -20

# 找命令
type ls
command -v python3
whereis ls

# 找图像
find . -type f \( -iname "*.jpg" -o -iname "*.png" \) -exec file --mime-type {} +
```

一句话：  
**找文件用 `find` / `fd` / `locate`，找内容用 `grep` / `rg`，找命令用 `type` / `command -v` / `whereis`，找图像用 `find + file/exiftool`，找大文件和重复文件用 `du` / `fdupes` / `ncdu`。**
