## 1. find：最强大、最常用

语法：

```bash
find [路径] [条件] [动作]
```





### 按文件名查找  -name

```bash
find . -name "*.log"              # 当前目录及子目录找 .log
find /etc -name "nginx.conf"      # 指定目录
find . -iname "*.jpg"             # 忽略大小写
find . -type f -name "*.sh"       # 只找普通文件
find . -type d -name "node_modules"  # 只找目录
```



### 按照文件类型找  -type

~~~shell
文件类型
-d		#directory 文件（夹）
-l		#link 链接
-f 		#file 文件
~~~







### 限制深度

```bash
find . -maxdepth 2 -name "*.conf"
find . -mindepth 1 -maxdepth 3 -type f
```







### 按大小查找  -size

```bash
find /var/log -size +100M         # 大于 100MB
find . -size -1k                  # 小于 1KB
find . -size 10M                  # 约等于 10MB
```



~~~shell
# 大小
+大于
a

~~~









### 按时间查找  -

```bash
find . -mtime -7                  # 7天内修改过
find . -mtime +30                 # 30天前修改过
find . -atime -1                  # 1天内访问过
find . -cmin -60                  # 60分钟内状态改变过
```







### 按权限、用户、属组

```bash
find . -perm 644
find . -user root
find . -group www-data
```







### 查找空文件或空目录

```bash
find . -empty
find . -type f -empty
find . -type d -empty
```







### 查找并执行操作

```bash
find . -name "*.tmp" -delete
find . -type f -name "*.log" -exec rm -i {} \;
find . -type f -name "*.sh" -exec chmod +x {} \;
```

更高效地批量处理：

```bash
find . -type f -name "*.log" -exec rm {} +
find . -name "*.log" -print0 | xargs -0 rm
```





### 逻辑组合

```bash
find . -name "*.jpg" -o -name "*.png"
find . \( -name "*.jpg" -o -name "*.png" \) -type f
find . ! -name "*.txt"
```

多个条件搜索 逻辑运算符

-and  与

-or 或

-not 非



优先级（）     转义字符 \ (\)



## 2. locate：基于数据库，速度快

`locate` 从系统数据库中查找，速度很快，但新文件可能查不到。

```bash
sudo updatedb        # 更新数据库
locate nginx.conf
locate -i readme     # 忽略大小写
locate -r '\.conf$'  # 正则匹配
```







## 3. which / whereis / type：查找命令位置

```bash
which python3        # 在 PATH 中查找可执行文件
whereis ls           # 查找二进制、源码、man 手册
type ls              # 判断是别名、内置命令还是外部命令
type -a python       # 显示所有匹配
command -v docker    # 常用于脚本中
```







## 4. grep / rg：按文件内容查找

查找哪些文件包含某个字符串：

```bash
grep -r "TODO" .
grep -rn "error" /var/log
grep -r --include="*.py" "import os" .
grep -r --exclude-dir=.git "foo" .
```

推荐使用 `ripgrep`，速度更快：

```bash
rg "TODO"
rg -t py "import os"
rg --hidden "pattern"
```













## 5. fd：更现代的 find 替代品

```bash
fd "*.log"
fd -e txt
fd -t f "config"
fd -H "secret"      # 包含隐藏文件
```

Ubuntu/Debian 安装后命令可能是 `fdfind`。

## 6. 简单通配符查找

```bash
ls *.txt
ls **/*.txt        # 需要先 shopt -s globstar
```

## 选择建议

| 需求                         | 推荐命令                     |
| ---------------------------- | ---------------------------- |
| 按名称、大小、时间、权限查找 | `find`                       |
| 快速全局按名称查找           | `locate`                     |
| 查找命令所在位置             | `which` / `whereis` / `type` |
| 按文件内容查找               | `grep` / `rg`                |
| 日常简洁查找                 | `fd`                         |

最常用示例：

```bash
find / -type f -name "*.conf" 2>/dev/null
find . -type f -mtime -1
grep -rn "关键字" .
```
