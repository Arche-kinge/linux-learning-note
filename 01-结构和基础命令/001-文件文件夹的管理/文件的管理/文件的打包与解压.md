来，一份 Linux 压缩打包解压速查。

## 1. 先分清：打包 ≠ 压缩
- **打包**：把一堆文件合成一个文件，比如 `tar`
- **压缩**：把文件体积变小，比如 `gzip`、`bzip2`、`xz`
- `.tar.gz` = 先 `tar` 打包，再用 `gzip` 压缩
- `.zip`、`.7z` 则是打包+压缩一体

---

## 2. tar 最常用

### 打包压缩
```bash
# 压成 .tar.gz，最常用
tar -czvf archive.tar.gz dir/

# 压成 .tar.bz2
tar -cjvf archive.tar.bz2 dir/

# 压成 .tar.xz，体积通常更小
tar -cJvf archive.tar.xz dir/

# 只打包不压缩
tar -cvf archive.tar dir/
```



> 参数含义：
>
> `c`：创建
>
> `x`：解压
>
> `t`：查看内容
>
> `z`：gzip
>
> `j`：bzip2
>
> `J`：xz
>
> `v`：显示过程
>
> `f`：指定文件名，后面紧跟压缩包名

<mark>常用：</mark>

<mark>压缩：tar -cvf 包名.tar 文件列表</mark>



### 解压
```bash
tar -xzvf archive.tar.gz
tar -xjvf archive.tar.bz2
tar -xJvf archive.tar.xz
tar -xvf archive.tar
```

### 解压到指定目录
```bash
tar -xzvf archive.tar.gz -C /tmp/target/
```

### 查看压缩包内容，不解压
```bash
tar -tzvf archive.tar.gz
```

### 排除文件/目录
```bash
tar -czvf archive.tar.gz dir/ \
  --exclude='dir/node_modules' \
  --exclude='*.log'
```



<mark>解压：tar -xvf 包名.tar 文件列表</mark>

## 3. gzip / bzip2 / xz 单文件压缩

它们通常只压缩单个文件，原文件默认会消失。

```bash
# gzip
gzip file.txt          # 生成 file.txt.gz，删除原文件
gzip -k file.txt       # 保留原文件
gunzip file.txt.gz     # 解压
gzip -d file.txt.gz    # 解压

# bzip2
bzip2 -k file.txt
bunzip2 file.txt.bz2

# xz
xz -k file.txt
unxz file.txt.xz
```

测试压缩包是否完整：
```bash
gzip -t file.gz
bzip2 -t file.bz2
xz -t file.xz
```

---

## 4. zip / unzip

跨平台常用，Windows 也能直接打开。

```bash
# 压缩目录
zip -r archive.zip dir/

# 解压到当前目录
unzip archive.zip

# 解压到指定目录
unzip archive.zip -d /tmp/target/

# 查看内容
unzip -l archive.zip

# 测试完整性
unzip -t archive.zip
```

排除文件：
```bash
zip -r archive.zip dir/ -x "dir/node_modules/*"
```

---

## 5. 7z

压缩率高，需安装 `p7zip-full` 之类。

```bash
# 压缩
7z a archive.7z dir/

# 解压
7z x archive.7z

# 解压到指定目录
7z x archive.7z -o/tmp/target/

# 查看
7z l archive.7z

# 测试
7z t archive.7z
```

## 6. 常见格式速查

| 格式               | 压缩                       | 解压                  |
| ------------------ | -------------------------- | --------------------- |
| `.tar`             | `tar -cvf a.tar dir/`      | `tar -xvf a.tar`      |
| `.tar.gz` / `.tgz` | `tar -czvf a.tar.gz dir/`  | `tar -xzvf a.tar.gz`  |
| `.tar.bz2`         | `tar -cjvf a.tar.bz2 dir/` | `tar -xjvf a.tar.bz2` |
| `.tar.xz`          | `tar -cJvf a.tar.xz dir/`  | `tar -xJvf a.tar.xz`  |
| `.gz`              | `gzip file`                | `gunzip file.gz`      |
| `.bz2`             | `bzip2 file`               | `bunzip2 file.bz2`    |
| `.xz`              | `xz file`                  | `unxz file.xz`        |
| `.zip`             | `zip -r a.zip dir/`        | `unzip a.zip`         |
| `.7z`              | `7z a a.7z dir/`           | `7z x a.7z`           |

## 7. 小贴士
- 最常用就记：  
  **压缩** `tar -czvf xxx.tar.gz 目录/`  
  **解压** `tar -xzvf xxx.tar.gz`
- `v` 会输出大量文件名，脚本里可去掉。
- 解压前最好先 `tar -tzvf` 或 `unzip -l` 看内容，避免覆盖。
- Linux 权限、软链接用 `tar` 保存更好；`zip` 对 Linux 权限支持较弱。
- 想更快可用 `pigz`、`zstd`：
  ```bash
  tar -I pigz -cvf a.tar.gz dir/
  tar --zstd -cvf a.tar.zst dir/
  ```
