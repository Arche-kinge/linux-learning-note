Linux 里的命令，按“由谁执行、在哪里执行”可以分为两类：

- **内部命令 / 内建命令 / shell builtin**：由 shell 自己实现的命令。
- **外部命令**：独立的可执行文件，放在磁盘上，通过 `$PATH` 找到后执行。

一句话记：  
**内部命令是 shell 的一部分；外部命令是磁盘上的程序。**

## 核心区别

| 维度               | 内部命令                                  | 外部命令                           |
| ------------------ | ----------------------------------------- | ---------------------------------- |
| 谁实现             | shell 自己，如 bash                       | 独立程序                           |
| 在哪里             | 在 bash 可执行文件内部                    | 文件系统中，如 `/usr/bin/ls`       |
| 怎么执行           | 当前 shell 进程直接执行                   | fork 子进程 + exec                 |
| 能否改变当前 shell | 能，如 `cd`、`export`                     | 不能，只影响子进程                 |
| 查找方式           | `type`、`help`                            | `which`、`whereis`、`man`          |
| 性能               | 快，无进程创建                            | 慢，要创建子进程                   |
| 例子               | `cd`、`export`、`read`、`source`、`alias` | `ls`、`cat`、`grep`、`find`、`git` |
| 帮助方式           | `help 命令`                               | `命令 --help`、`man 命令`          |

## 为什么 `cd` 必须是内部命令？

因为 `cd` 要改变“当前 shell 的工作目录”。

如果 `cd` 是外部命令，它会在子进程里执行，子进程目录变了，父 shell 目录没变，你退出子进程后还在原地。

```bash
cd /tmp
pwd
# /tmp
```

`export`、`source`、`read`、`umask`、`ulimit` 也一样，必须影响当前 shell，所以是内建命令。

## 怎么判断一个命令是内部还是外部？

最推荐 `type`：

```bash
type cd
# cd is a shell builtin

type ls
# ls is /usr/bin/ls

type -a echo
# echo is a shell builtin
# echo is /usr/bin/echo
```

`type -t` 只输出类型：

```bash
type -t cd
# builtin

type -t ls
# file

type -t ll
# alias
```

其他判断方式：

```bash
command -V cd
# cd is a shell builtin

enable -a | grep cd
```

`which` 和 `whereis` 主要查外部命令：

```bash
which ls
# /usr/bin/ls

which cd
# 通常找不到，因为 cd 是内建
```

## 常见内部命令

用 `help` 可以列出 bash 内建命令：

```bash
help
```

常见的有：

- 目录相关：`cd`、`pwd`、`pushd`、`popd`、`dirs`
- 环境相关：`export`、`unset`、`set`、`shopt`、`umask`、`ulimit`
- 脚本相关：`source`、`.`、`read`、`eval`、`exec`、`exit`、`return`
- 别名/函数：`alias`、`unalias`、`declare`、`local`
- 作业控制：`jobs`、`fg`、`bg`、`wait`、`kill`
- 判断/流程：`test`、`[`、`type`、`command`、`builtin`
- 输出输入：`echo`、`printf`、`read`

注意：有些命令既有内建版本，也有外部版本，比如：

```bash
type -a echo
type -a pwd
type -a test
type -a kill
type -a printf
```

## 常见外部命令

```bash
ls
cat
grep
find
sed
awk
tar
git
python
docker
man
which
whereis
```

它们都是独立文件：

```bash
which grep
# /usr/bin/grep

file /usr/bin/grep
# ELF executable
```

## 同名命令的优先级

当你在 shell 输入一个命令，查找顺序大致是：

1. 别名 alias
2. 关键字，如 `if`、`for`、`while`
3. 函数 function
4. 内建命令 builtin
5. `$PATH` 中的外部命令

所以 `echo` 默认走内建，而不是 `/bin/echo`：

```bash
type -a echo
# echo is a shell builtin
# echo is /usr/bin/echo
```

想强制用外部命令：

```bash
/bin/echo "hello"
env echo "hello"
```

想强制用内建：

```bash
builtin echo "hello"
```

想禁用内建 `echo`：

```bash
enable -n echo
echo "hello"      # 现在会走 /usr/bin/echo
enable echo       # 恢复内建
```

## 帮助怎么查？

内部命令：

```bash
help cd
help -m cd
man bash          # 搜 SHELL BUILTIN COMMANDS
```

外部命令：

```bash
ls --help
man ls
info ls
```

所以之前的问题可以这样串起来：

- `type -a 命令`：判断内部还是外部，以及所有来源。
- `help 内建命令`：查 shell 内建命令。
- `man 外部命令`：查外部命令手册。
- `which/whereis`：只适合查外部命令位置。
- `command -v 命令`：脚本里判断命令是否存在，内建和外部都支持。

## 总结

- 内部命令：shell 自带，直接在当前 shell 执行，能改变 shell 状态。
- 外部命令：独立程序，通过 `$PATH` 查找，在子进程执行。
- 判断用 `type -a`。
- 查内建帮助用 `help`。
- 查外部帮助用 `man` 和 `--help`。
- `which`、`whereis` 查不到内建命令是正常现象。
