Linux 里“查命令怎么用、命令是干嘛的”这类工具很多，
常见有 
`man`、`info`、`--help`、`help`、`whatis`、`apropos`、`type`、`command -v`、`which`、`whereis`、`tldr` 等。
它们分工不同。

## 总览

|         命令         |        查什么         |       示例       |          备注          |
| :------------------: | :-------------------: | :--------------: | :--------------------: |
|    `命令 --help`     |  命令自带的快速帮助   |   `ls --help`    |    最快，但可能不全    |
|        `man`         |      正式手册页       |     `man ls`     |     最权威、最详细     |
|        `info`        |     GNU 详细文档      | `info coreutils` |   比 man 更像电子书    |
|        `help`        |   bash 内建命令帮助   |    `help cd`     |  只对 shell 内建有效   |
|       `whatis`       |      一句话说明       |   `whatis ls`    |     看命令是干嘛的     |
| `apropos` / `man -k` |    按关键字搜手册     |  `apropos copy`  |     忘记命令名时用     |
|        `type`        |       命令类型        |   `type -a ls`   |  别名/函数/内建/外部   |
|     `command -v`     |     命令解析结果      | `command -v git` | 脚本里判断命令是否存在 |
|       `which`        |  PATH 中的可执行文件  |  `which python`  |     不认内建、别名     |
|      `whereis`       | 二进制、man、源码位置 |   `whereis ls`   |      不搜整个磁盘      |
|        `tldr`        |       常用示例        |    `tldr tar`    |       需额外安装       |
|       `cheat`        |        速查表         |   `cheat tar`    |       需额外安装       |

## 1. man：最正式的手册

```bash
man ls
man 5 passwd
man 1 passwd
man -k copy      # 按关键字搜，等价 apropos
man -f ls        # 等价 whatis ls
```

`man` 手册分章节：

- `1` 用户命令，如 `man 1 ls`
- `2` 系统调用
- `3` 库函数
- `4` 设备
- `5` 文件格式，如 `man 5 passwd`
- `8` 系统管理命令

同一名字可能出现在不同章节，比如 `passwd` 既是命令又是文件格式。

## 2. --help：最快看选项

大多数外部命令都支持：

```bash
ls --help
grep --help
git --help
```

有些命令用子命令帮助：

```bash
git help commit
docker help run
```

注意：`-h` 不一定是帮助，有些命令里 `-h` 是 host、human 等含义，优先用 `--help`。

## 3. help：查 bash 内建命令

`cd`、`echo`、`type`、`alias` 这些是 shell 内建，`man cd` 可能不对，应该用：

```bash
help
help cd
help -m cd      # 用 man 风格显示
help -d cd      # 简短描述
```

## 4. whatis：一句话说明

```bash
whatis ls
# ls (1) - list directory contents
```

它来自 `whatis` 数据库，如果结果过期，可以更新：

```bash
sudo mandb
```

## 5. apropos / man -k：按关键字搜命令

忘记命令名时用：

```bash
apropos copy
man -k copy
apropos -s 1 copy    # 只搜第 1 章节
```

例如你想找“复制文件”的命令，搜 `copy` 可能看到 `cp`、`scp`、`rsync` 等。

## 6. info：GNU 的详细文档

```bash
info ls
info coreutils
```

`info` 内容通常比 `man` 更详细，支持超链接导航。很多 GNU 工具同时有 man 和 info。

## 7. type / command -v：判断命令到底是什么

```bash
type ls
type -a ls
type -t ls
# alias / function / builtin / file / keyword

command -v git
command -V git
```

脚本中判断命令是否存在，推荐：

```bash
if command -v git >/dev/null 2>&1; then
  echo "git 存在"
fi
```

## 8. which / whereis：查位置，不是查用法

```bash
which python
which -a python

whereis ls
whereis -b ls
whereis -m ls
```

`which` 查 PATH 里的可执行文件；`whereis` 查二进制、man、源码位置。它们不负责解释命令怎么用。

## 9. tldr / cheat：看常用例子

`man` 太详细时，可以用：

```bash
tldr tar
tldr find
cheat tar
```

没安装也可以直接：

```bash
curl cheat.sh/tar
```

## 怎么选

- 快速看选项：`命令 --help`
- 详细看用法：`man 命令`
- shell 内建命令：`help 命令`
- 命令是干嘛的：`whatis 命令`
- 忘了命令名：`apropos 关键字` 或 `man -k 关键字`
- 想看例子：`tldr 命令`
- 判断命令来源：`type -a 命令`、`command -v 命令`
- 查文件位置：`which`、`whereis`

最常用组合：

```bash
命令 --help
man 命令
help 内建命令
apropos 关键字
tldr 命令
```
