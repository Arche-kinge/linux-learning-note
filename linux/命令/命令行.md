Linux 命令行是通过 **Shell**（如 Bash、Zsh）与系统交互的方式。基本格式：

```bash
命令 [选项] [参数]
```

普通用户提示符通常是 `$`，root 用户是 `#`。

## 1. 最常用基础命令

```bash
pwd                 # 显示当前目录
ls                  # 列出文件
ls -lah             # 详细列表，含隐藏文件，易读大小
cd /var/log         # 进入目录
cd ..               # 返回上一级
cd ~                # 回到用户主目录
clear               # 清屏
history             # 查看历史命令
man ls              # 查看命令手册
ls --help           # 查看帮助
```

快捷键：

- `Tab`：自动补全
- `Ctrl + C`：终止当前命令
- `Ctrl + D`：退出当前 Shell
- `Ctrl + L`：清屏
- `↑ / ↓`：历史命令

## 2. 文件与目录

```bash
touch file.txt              # 创建空文件
mkdir dir                   # 创建目录
mkdir -p a/b/c              # 递归创建目录
cp file.txt /tmp/           # 复制文件
cp -r dir /tmp/             # 复制目录
mv old.txt new.txt          # 移动/重命名
rm file.txt                 # 删除文件
rm -rf dir                  # 强制递归删除目录，慎用
cat file.txt                # 查看文件内容
less file.txt               # 分页查看
head -n 20 file.txt         # 前 20 行
tail -n 20 file.txt         # 后 20 行
tail -f app.log             # 实时查看日志
```

权限：

```bash
chmod 755 script.sh         # 设置权限
chown user:group file       # 修改所属用户和组
```

## 3. 查找与文本处理

```bash
find / -name "*.conf" 2>/dev/null
find . -type f -size +100M
grep "error" app.log
grep -r "keyword" /etc
wc -l file.txt
sort file.txt
uniq
cut -d: -f1 /etc/passwd
sed 's/old/new/g' file.txt
awk '{print $1}' file.txt
```

## 4. 管道与重定向

```bash
command > file.txt          # 覆盖输出到文件
command >> file.txt         # 追加输出
command 2> error.log        # 错误输出
command > out.log 2>&1      # 标准输出和错误都写入
command1 | command2         # 管道
ps aux | grep nginx
```

## 5. 进程与系统

```bash
ps aux                      # 查看进程
top                         # 动态查看进程
htop                        # 更友好的进程查看
kill PID                    # 结束进程
kill -9 PID                 # 强制结束
jobs                        # 查看后台任务
bg                          # 后台运行
fg                          # 前台运行
nohup command &             # 后台持久运行
systemctl status nginx      # 服务状态
systemctl restart nginx     # 重启服务
df -h                       # 磁盘空间
du -sh *                    # 当前目录各项大小
free -h                     # 内存
uname -a                    # 系统信息
uptime                      # 运行时间/负载
```

## 6. 网络

```bash
ip addr                     # 查看 IP
ping example.com
curl -I https://example.com
wget https://example.com/file.zip
ssh user@host
scp file.txt user@host:/tmp/
rsync -avz src/ user@host:/dest/
ss -tulnp                   # 查看监听端口
```

## 7. 压缩与解压

```bash
tar -czvf archive.tar.gz dir/      # 压缩
tar -xzvf archive.tar.gz           # 解压
zip -r archive.zip dir/
unzip archive.zip
```

## 8. 包管理

不同发行版：

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install nginx

# CentOS / RHEL / Fedora
sudo dnf install nginx

# Arch
sudo pacman -S nginx
```
