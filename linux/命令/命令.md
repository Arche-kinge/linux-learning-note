# 1.基本命令：

## 1.1 ls

```bash
-A
-a
-l
-t

综合指令 ls -alt

```



`			ls -alt` 会列出：

- **当前目录下的所有文件和目录**
- **包括隐藏文件**（以 `.` 开头的文件，也会列出 `.` 和 `..`）
- **以长格式显示**：权限、链接数、所有者、所属组、大小、修改时间、文件名
- **按修改时间排序**：最近修改的排在最前面

等价于：

```bash
ls -a -l -t
```

常用输出含义：

```text
-rw-r--r-- 1 user group 1234 Oct  9 10:00 file.txt
drwxr-xr-x 2 user group 4096 Oct  8 09:00 dir
lrwxrwxrwx 1 user group    7 Oct  7 08:00 link -> target
```

- 第 1 个字符-文件属性（一共10个属性）：

  ​	`-` 普通文件，`d` 目录，`l` 软链接

   	





- 三组权限属性`rw-r--r--`：

  rwx-

  对于10进制的4210

  （2^2=4 |2^1=2 |2^0=1|2^-1=0 ）

  三组权限为 所有者（owner） 用户组（user） 公共（）

  

  每一组为3个属性的二进制表示

三个权限属性为r（read）w（write）x（），-则为该属性无权限





- `user group`：所有者和组
- `1234`：大小
- `Oct 9 10:00`：修改时间
- `file.txt`：文件名

注意：`ls -alt` **不会递归列出子目录内容**。  
如果想看子目录，要用：

```bash
ls -altR
```

如果想让大小更易读，可以加 `-h`：

```bash
ls -alth
```
