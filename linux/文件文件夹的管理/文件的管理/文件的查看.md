# less

分页查看

`less` 常用操作：

- `空格`：下一页
- `b`：上一页
- `g`：首行
- `G`：末尾
- `/关键词`：搜索
- `n` / `N`：下一个 / 上一个匹配
- `F`：实时跟踪，类似 `tail -f`
- `Ctrl+C`：退出实时跟踪

clear

查看 Linux 文件，先分清：**看内容、看类型、看元数据、看特殊格式**。不要一上来就 `cat` 大文件，尤其是日志和二进制文件。

## 1. 先判断文件类型和元数据

```bash
file file.txt              # 查看文件类型
file -i file.txt           # 查看 MIME 类型和编码
stat file.txt              # 查看大小、权限、时间、inode 等
ls -lh file.txt            # 查看权限、所有者、大小、时间
namei -l /path/to/file     # 查看路径每一级权限
```

## 2. 查看文本内容

### 小文件：直接输出

```bash
cat file.txt               # 输出全部内容
cat -n file.txt            # 带行号
cat -A file.txt            # 显示不可见字符，如 Tab、换行
tac file.txt               # 反向输出，最后一行先显示
nl file.txt                # 加行号
```

### 大文件：分页查看

```bash
less file.txt              # 推荐，大文件友好
less -N file.txt           # 显示行号
more file.txt              # 老式分页，功能少
```

`less` 常用操作：

- `空格`：下一页
- `b`：上一页
- `g`：首行
- `G`：末尾
- `/关键词`：搜索
- `n` / `N`：下一个 / 上一个匹配
- `F`：实时跟踪，类似 `tail -f`
- `Ctrl+C`：退出实时跟踪
- `q`：退出

### 只看开头或结尾

```bash
head file.txt              # 前 10 行
head -n 20 file.txt        # 前 20 行
head -c 100 file.txt       # 前 100 字节
head -n -5 file.txt        # 除最后 5 行外全部

tail file.txt              # 后 10 行
tail -n 20 file.txt        # 后 20 行
tail -n +2 file.txt        # 从第 2 行到末尾
tail -f app.log            # 实时跟踪日志
tail -F app.log            # 实时跟踪，日志轮转后继续跟
```

### 查看指定行

```bash
sed -n '10,20p' file.txt               # 第 10 到 20 行
awk 'NR>=10 && NR<=20' file.txt        # 同上
sed -n '100p' file.txt                 # 第 100 行
```

### 搜索和过滤

```bash
grep "error" app.log                   # 搜索内容
grep -n "error" app.log                # 显示行号
grep -C 3 "error" app.log              # 显示前后 3 行
grep -i "error" app.log                # 忽略大小写
grep -v "debug" app.log                # 排除包含 debug 的行
grep -r "timeout" /etc/                # 递归搜索目录
```

### 统计和列查看

```bash
wc -l file.txt             # 行数
wc -w file.txt             # 单词数
wc -c file.txt             # 字节数

cut -d: -f1 /etc/passwd    # 按冒号分隔，取第 1 列
column -t file.txt         # 对齐列，适合表格文本
sort file.txt              # 排序
uniq -c file.txt           # 统计连续重复行
```

## 3. 实时查看日志

```bash
tail -f /var/log/syslog
tail -F /var/log/nginx/access.log
less +F /var/log/syslog
watch -n 1 'cat /proc/loadavg'
```

过滤实时日志：

```bash
tail -f app.log | grep --line-buffered "ERROR"
```

## 4. 查看压缩文件

```bash
zcat file.gz | less
zless file.gz
zgrep "error" file.gz
```

`.tar.gz` 中查看文件：

```bash
tar -tzf archive.tar.gz            # 列出内容
tar -xzf archive.tar.gz file.txt   # 解压单个文件
```

## 5. 查看二进制文件

不要直接 `cat` 二进制文件。

```bash
strings binary | less              # 提取可打印字符串
strings -n 6 binary | less         # 长度至少 6 的字符串
xxd file | less                    # 十六进制查看
hexdump -C file | less             # 十六进制 + ASCII
od -c file | less                  # 八进制/字符查看
```

## 6. 查看结构化数据

```bash
jq . data.json                     # JSON 格式化查看
python -m json.tool data.json      # 没有 jq 时可用
yq . config.yaml                   # YAML 查看
xmllint --format data.xml          # XML 格式化
```

CSV 可配合：

```bash
column -s, -t data.csv
```

## 7. 编码转换查看

```bash
file -i file.txt                   # 查看编码
iconv -f GBK -t UTF-8 file.txt     # 转为 UTF-8 输出
iconv -f GBK -t UTF-8 file.txt -o file.utf8
```

## 8. 比较文件

```bash
diff file1 file2                   # 文本差异
cmp file1 file2                    # 二进制差异
md5sum file                        # 校验值
```

## 9. 常用命令速查

```bash
cat file.txt
less -N file.txt
head -n 20 file.txt
tail -n 20 file.txt
tail -f app.log
sed -n '10,20p' file.txt
grep -n "error" file.txt
wc -l file.txt
file file.txt
stat file.txt
strings binary | less
xxd file | less
zless file.gz
jq . data.json
```

总结一句：  
**小文本用 `cat`，大文本用 `less`，看头尾用 `head/tail`，实时日志用 `tail -f` 或 `less +F`，搜索用 `grep`，指定行用 `sed/awk`，二进制用 `strings/xxd`，压缩文件用 `zless/zcat`。**
