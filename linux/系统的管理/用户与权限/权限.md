rwx（read|write|execute）

`rwx` 里的 **x 指代英文 `execute`**，意思是“执行”。

三个权限分别是：

- `r` = **read**，读
- `w` = **write**，写
- `x` = **execute**，执行

所以 `rwx` 就是 **read, write, execute**。

补充一下 `x` 的具体含义：

- 对**普通文件**：表示这个文件可以当作程序或脚本运行，例如 `./script.sh`
- 对**目录**：表示可以进入这个目录，或者访问目录里的文件，例如 `cd dir`
- 没有 `x` 时：文件不能执行，目录不能进入





```zsh
特殊权限 | 所有者 u | 所属组 g | 其他人 o

```



~~~zsh
r 4d 4o 100b
w 2d 2o 010b
x 1d 1o 001b
_ 0d 1o 00b
~~~

**普通权限 = u / g / o 三组，每组 rwx，一共三位八进制。**

~~~
000 ___ 0

001__x 1

010_w_ 2

011_wx 3

100 r__ 4

101 r_x  5

110 rw_ 6

111 rwx 7
~~~



而 **特殊权限**不是第 4 组用户，它是加在前面的一位：

```
4 = SUID
2 = SGID
1 = Sticky
```



```
4755
│└── 普通权限 755
└── 特殊权限 4 = SUID
```



```
1777
│└── 普通权限 777
└── 特殊权限 1 = Sticky
```

## 常见普通权限

普通权限就是三位八进制：`u g o`。

| 数字  | 符号        | 含义                          | 常见用途             | 安全评价       |
| ----- | ----------- | ----------------------------- | -------------------- | -------------- |
| `644` | `rw-r--r--` | 所有者读写，其他人只读        | 普通文件、网页文件   | 很常见，较安全 |
| `600` | `rw-------` | 只有所有者读写                | SSH 私钥、私有文件   | 安全           |
| `640` | `rw-r-----` | 所有者读写，组只读            | 配置文件、日志       | 较安全         |
| `664` | `rw-rw-r--` | 所有者和组可读写，其他人只读  | 组内共享文件         | 常见           |
| `700` | `rwx------` | 只有所有者可读写执行          | 私有目录、脚本       | 安全           |
| `755` | `rwxr-xr-x` | 所有者可写，其他人读/执行     | 可执行文件、目录     | 很常见         |
| `750` | `rwxr-x---` | 组可读/执行，其他人无权限     | 服务目录             | 较安全         |
| `775` | `rwxrwxr-x` | 所有者和组可写，其他人读/执行 | 组内协作目录         | 常见，但看场景 |
| `777` | `rwxrwxrwx` | 所有人可读写执行              | 临时测试、不推荐生产 | 极不安全       |

所以：

```text
777 = rwx rwx rwx
775 = rwx rwx r-x
755 = rwx r-x r-x
644 = rw- r-- r--
600 = rw- --- ---
```

## `777` 和 `775` 的区别

```text
777：所有人 都能读、写、执行/进入
775：所有人 都能读、执行/进入，但只有所有者和组能写
```

对目录来说：
- `x` 决定能不能进入目录
- `w` 决定能不能在目录里创建、删除、重命名文件

所以 `777` 目录非常危险：

```text
任何人都能进入、创建文件、删除文件
```

`/tmp` 虽然是 `1777`，但前面有个 `1`，叫 **Sticky 位**：

```text
1777 = rwxrwxrwt
```

意思是：大家都能写，但**只能删自己的文件**，不能随便删别人的。

## 特殊权限也常见

| 数字   | 名称   | 常见例子          |
| ------ | ------ | ----------------- |
| `4755` | SUID   | `/usr/bin/passwd` |
| `2755` | SGID   | 组协作目录        |
| `1777` | Sticky | `/tmp`            |

## 实际建议

- 普通文件常用：`644`、`600`、`640`、`664`
- 可执行文件和目录常用：`755`、`700`、`750`
- 组内协作目录：`775`、`2775`
- 临时开放：`1777`，如 `/tmp`
- **尽量不要用 `777`**，尤其不要给网站目录、系统目录、家目录随便 `777`

一句话总结：

> `777`、`775` 确实常见，但 `755`、`644`、`600`、`700` 更常见也更安全。  
> `777` 属于“能跑但危险”，生产环境应尽量避免。
