Vim 是 “Vi Improved”，兼容 vi。Linux 里很多 `vi` 其实就是 vim 的软链接或精简版，所以学会 vim 基本就会用 vi。

## 1. 核心：Vim 是模式编辑器

最常用四种模式：

- **普通模式**：默认模式，用来移动、删除、复制、粘贴
- **插入模式**：输入文字
- **可视模式**：选中文本
- **命令行模式**：输入 `:`、`/`、`?` 开头的命令

任何时候不知道自己在哪，按 `Esc` 回到普通模式。

## 2. 最简使用流程

```bash
vim 文件名
```

进入后：

```text
i       进入插入模式，开始输入
Esc     回到普通模式
:wq     保存并退出
```

如果不想保存：

```text
Esc
:q!     强制退出不保存
```

## 3. 启动、保存、退出

| 操作           | 命令                            |
| -------------- | ------------------------------- |
| 打开文件       | `vim file.txt`                  |
| 保存           | `:w`                            |
| 退出           | `:q`                            |
| 保存退出       | `:wq` 或 `:x` 或普通模式下 `ZZ` |
| 强制退出不保存 | `:q!`                           |
| 强制保存退出   | `:wq!`                          |
| 另存为         | `:w newfile`                    |

## 4. 进入插入模式

在普通模式下：

| 命令 | 作用               |
| ---- | ------------------ |
| `i`  | 光标前插入         |
| `a`  | 光标后插入         |
| `I`  | 行首插入           |
| `A`  | 行尾插入           |
| `o`  | 下方新建一行并插入 |
| `O`  | 上方新建一行并插入 |
| `s`  | 删除当前字符并插入 |
| `S`  | 删除整行并插入     |

## 5. 光标移动

普通模式下：

| 命令                | 作用                |
| ------------------- | ------------------- |
| `h j k l`           | 左、下、上、右      |
| `0`                 | 行首                |
| `^`                 | 第一个非空白字符    |
| `$`                 | 行尾                |
| `gg`                | 文件开头            |
| `G`                 | 文件末尾            |
| `nG` 或 `:n`        | 跳到第 n 行         |
| `w` / `b`           | 下一个词 / 上一个词 |
| `Ctrl+f` / `Ctrl+b` | 向下 / 向上翻页     |
| `Ctrl+d` / `Ctrl+u` | 向下 / 向上半页     |

## 6. 删除、复制、粘贴、撤销

| 命令        | 作用              |
| ----------- | ----------------- |
| `x`         | 删除当前字符      |
| `dd`        | 删除当前行        |
| `dw`        | 删除一个词        |
| `d$`        | 删除到行尾        |
| `dG`        | 删除到文件末尾    |
| `yy`        | 复制当前行        |
| `yw`        | 复制一个词        |
| `p`         | 粘贴到光标后/下方 |
| `P`         | 粘贴到光标前/上方 |
| `u`         | 撤销              |
| `Ctrl+r`    | 重做              |
| `.`         | 重复上一次操作    |
| `r`         | 替换一个字符      |
| `R`         | 进入替换模式      |
| `cc` 或 `S` | 修改整行          |
| `cw`        | 修改一个词        |
| `J`         | 合并下一行        |

数字可配合使用，如：

```text
3dd     删除3行
5yy     复制5行
2p      粘贴2次
```

## 7. 可视模式

| 命令             | 作用             |
| ---------------- | ---------------- |
| `v`              | 字符可视模式     |
| `V`              | 行可视模式       |
| `Ctrl+v`         | 块可视模式       |
| 选中后 `d`       | 删除             |
| 选中后 `y`       | 复制             |
| 选中后 `c`       | 修改             |
| 选中后 `>` / `<` | 缩进 / 反缩进    |
| 选中后 `:`       | 对选中行执行命令 |

例如选中多行后输入：

```text
:s/old/new/g
```

表示在选中范围内替换。

## 8. 搜索与替换

| 命令      | 作用                 |
| --------- | -------------------- |
| `/word`   | 向下搜索 word        |
| `?word`   | 向上搜索 word        |
| `n` / `N` | 下一个 / 上一个匹配  |
| `*`       | 搜索当前光标下的单词 |
| `:noh`    | 取消搜索高亮         |

替换：

```text
:s/old/new/          当前行第一个 old 替换为 new
:s/old/new/g         当前行全部替换
:%s/old/new/g        全文替换
:%s/old/new/gc       全文替换并逐个确认
:1,10s/old/new/g     第1到10行替换
```

## 9. 分屏、标签页

| 命令                 | 作用                  |
| -------------------- | --------------------- |
| `:sp file`           | 水平分屏              |
| `:vsp file`          | 垂直分屏              |
| `Ctrl+w` + `h/j/k/l` | 在分屏间切换          |
| `:close`             | 关闭当前窗口          |
| `:only`              | 只保留当前窗口        |
| `:tabnew file`       | 新建标签页            |
| `gt` / `gT`          | 下一个 / 上一个标签页 |

## 10. 常用设置

临时设置：

```text
:set nu          显示行号
:set nonu        取消行号
:set ic          忽略大小写
:set noic        区分大小写
:set paste       粘贴模式，防止自动缩进混乱
:syntax on       开启语法高亮
```

永久配置写入 `~/.vimrc`：

```vim
set number
set tabstop=4
set shiftwidth=4
set expandtab
set autoindent
syntax on
```

## 11. vi 和 vim 的区别

- **vi**：更老、更基础，POSIX 标准编辑器
- **vim**：vi 的增强版，支持语法高亮、多级撤销、分屏、标签页、插件、脚本、补全等
- 大多数 Linux 中，`vi` 命令实际调用的是 vim
- 学习时优先学 vim，vi 基本兼容常用命令

## 12. 推荐练习

终端直接运行：

```bash
vimtutor
```

这是 Vim 自带的交互式教程，跟着做一遍就能掌握大部分基础操作。

记住一句话：**按 `Esc` 回普通模式，再输入命令。** 最常见退出方式就是 `:wq` 和 `:q!`。
