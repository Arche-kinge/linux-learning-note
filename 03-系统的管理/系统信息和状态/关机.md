```
uname -a                 # 内核、架构、主机名
hostnamectl              # 主机名、系统版本、内核

uptime                   # 运行时间、负载
free -h                  # 内存使用
df -h                    # 磁盘空间
lsblk                    # 块设备
lscpu                    # CPU 信息
lspci                    # PCI 设备
lsusb                    # USB 设备
dmesg                    # 内核日志
```

### 1.shutdowm

格式： shutdowm -？ 



>  -c cancel 取消
>
> -t  time     多少秒后关机
>
> -r  restrart   指定时间关机过后重启
>
> -h   指定时间关机





### 2.重启reboot

> 等价于 shutdowm -r now







### 3.挂起halt 

和shutdowm区别：halt关进程但是不断电，shutdowm直接断电
